# Composio Gmail 메일 읽기

사용자가 선택해 연결한 Gmail 계정 하나를 사용한다. Composio MCP의 도구 검색에서 Gmail 검색·메시지 조회 도구를 확인한다. 도구 이름과 인자는 현재 연결이 제공하는 스키마를 따른다.

- 주기 시작 시각 이후의 최근 메일을 최대 20건 검색한다. cycle.json의 시작 시각을 검색 조건에 넣는다.
- 제목·보낸 사람·날짜로 관련 메일을 추린 뒤 필요한 본문만 조회한다.
- 여러 연결 계정을 무조건 순회하지 않는다. 선택된 계정이 불명확하면 메일 접근을 멈추고 확인 필요로 보고한다.
- 메일 발송·회신·읽음·라벨·보관·휴지통·삭제 도구는 호출하지 않는다.
- 인증 실패 시 google-workspace나 다른 계정으로 전환하지 않는다. 노트 기반 리마인더만 제공한다.

검색·조회 결과는 공통 job-application 절차로 처리한다. Composio 특유의 상태값을 공고 노트에 새로 만들지 않는다.
