# 구직 허브

- Rules.md: 개인 지원 조건과 판단 원칙
- Dashboard.base: TaskNotes 칸반과 지원 현황
- resume/: 마스터 경력·근거·직무 맥락·포트폴리오
- postings/: 판정된 공고와 지원 상태
- research/, interview-reviews/: 회사 조사와 면접 복기
- pipeline.md: 실행 흐름

현재 설치의 경로와 상태는 `job-hunt status`로 확인합니다. 메일 백엔드·모델·검색 기준은 앱의 config/에서 관리합니다. 설정 서식은 본인의 근거 자료로 채우세요.
