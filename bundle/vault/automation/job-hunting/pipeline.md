# 구직 파이프라인

공개 보드 수집 → 프로필 필터·중복 제거 → 선택적 공개 모델 분석 → 개인 경력 기반 판정 → 공고 노트 → 지원 문서·면접 준비.

- `job-hunt harvest`: Python 수집과 설정된 공개 모델 분석.
- `job-match`: 원문과 실제 경력 근거로 판정.
- `job-documents`: 기존 자료로 지원 문서 작성.
- `job-application`: 선택한 메일 백엔드로 검색·읽기 및 리마인더.
- `job-interview`: 회사 조사와 면접 연습.
- 별도 Aside 스킬: 플랫폼에 저장된 이력서 선택·폼 작성·명시된 권한 내 제출.

공개 분석 실패를 유료 모델로 자동 대체하지 않습니다. 구직 노트 쓰기는 전용 상태 폴더의 .kit-live로 허용합니다. 메일 변경과 지원 제출은 별개 권한이며, 메일 스킬은 읽기 전용입니다. 과거 기록 정리는 설치·업그레이드의 기본 동작에 포함하지 않습니다.
