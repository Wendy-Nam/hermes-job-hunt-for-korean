# 콘텐츠 제작 운영 규칙

콘텐츠·카드뉴스 작업 시 아래 규칙과 플로우를 확정한다.

## 콘텐츠 제작 규칙
- 일반론으로 끝내지 않고 실제 동작 가능한 시스템 설계를 기준으로 구체적인 적용법까지 포함한다.
- 비기술자 대상 콘텐츠는 전문용어를 걷어내고 일상적인 비유를 사용한다.
- AI 지식 보유자 대상 콘텐츠는 전문용어를 유지하되 쉬운 풀이를 붙이고 프롬프트 예시를 포함한다.
- 카드뉴스 텍스트는 충분히 작성하며 초안 작성, 승인, 제작 순서를 지킨다.

## 카드뉴스 제작 플로우
1. 초안 텍스트를 작성하고 사용자 승인을 받는다.
2. 카드 이미지는 렌더러 또는 전용 생성 도구를 통해 작성한다.
   - 크기는 1080×1920 portrait (9:16) 또는 4:5 (1080×1350) 캐러셀 기준.
3. 텍스트 가독성, 줄바꿈, 다크 테마 배색을 준수한다.
4. 출력 경로: `outputs/cardnews/<이름>.png` 또는 지정 경로.
5. 전달 전 파일 크기, 경로 및 텍스트 렌더링 상태를 검증한다.
