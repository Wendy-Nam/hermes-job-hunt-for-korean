# 볼트 문서 정리·리팩토링 기준 (컴팩트·유니크·명확·AI 가독성)

볼트 문서를 정리·리팩토링할 때는 아래 원칙을 따른다.

## 원칙 4축

### 1. 컴팩트 (Compact)
- 불필요한 중복·군더더기·낡은 내용은 제거하거나 덜어낸다.
- 한 사실은 한 곳에만 둔다. 같은 내용이 여러 문서에 있으면 정본 하나로 모은다.
- 문장·목록을 촘촘하게 줄인다.

### 2. 유니크 (Unique)
- 각 문서는 고유한 가치와 역할을 가져야 한다.
- 중복·복제 문서는 정본 위치 하나로 병합하고, 나머지는 아카이브 이동.
- 문서·섹션 간 내용이 겹치면 어느 쪽이 정본인지 결정하고 한쪽만 남긴다.

### 3. 명확 (Clear)
- 맥락이 안 읽히는 과한 줄임말을 피하고, 문서만 읽고도 이해되게 한다.
- 이전 대화 없이도 문맥을 파악할 수 있어야 한다.

### 4. AI 입력 가독성 (AI-parseable)
- 매 턴 주입·검색·파싱이 쉽도록 구조화한다:
  - frontmatter(title, type, date, tags, private 등)를 일관되게 작성.
  - 마크다운 구조(제목 계층·목록·테이블)를 일관되게 유지.
  - 위키링크(`[[...]]`)는 대상이 존재하도록 관리.

## 처리 순서
1. 읽고 → 내용·역할 파악.
2. 정본 위치 결정.
3. 중복 제거, 명확·압축 리팩토링, AI 가독성 구조로 재구성.
4. 원본 의미 훼손 여부 재확인.
5. 변경 로그 갱신.
