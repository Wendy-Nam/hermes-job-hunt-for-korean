# Aside 지원 자동화

Aside는 로그인된 사이트를 직접 다루는 macOS/Windows 브라우저입니다. 이 저장소의 Hermes 서버와 별도 환경에서 실행합니다. 공식 인터페이스는 [CLI·MCP·REPL](https://aside.com/developers)이며 공개 다운로드 API로 작업을 실행하지 않습니다.

## 설치

`integrations/aside/aside-job-apply` 폴더 전체를 Aside의 사용자 스킬로 등록합니다. SKILL.md만 복사하면 참조·정책 예시·제출 이력 스크립트가 빠집니다. Aside에 폴더 경로를 주고 `이 폴더를 aside-job-apply 사용자 스킬로 설치하고 인식되는지 확인해줘`라고 요청할 수 있습니다. 버전에 따른 파일 접근·설치 승인은 Aside 화면에서 완료합니다. 이 저장소의 installer는 Aside 계정 폴더를 수정하지 않습니다.

## 사용

1. 대상 채용 플랫폼에 본인 계정으로 로그인합니다.
2. 전용 작업 폴더에 정책 예시를 application-policy.json으로 복사합니다.
3. 계정 식별자, 허용 도메인, 공고 URL 또는 허용 탐색 조건, 제출 한도·기한을 채웁니다. 실제 후보자 자료를 처리할 수 있는 모델을 선택합니다.
4. 작성 모드로 이력서 선택·필드·첨부를 확인합니다.
5. 자동 제출을 원하면 해당 범위를 승인하고 mode를 auto_submit, authorized를 true로 지정합니다. 범위 안에서는 매 지원마다 같은 확인을 반복하지 않습니다.

예시 요청:

> 이 정책 안에서 공고를 확인하고, 플랫폼에 저장된 이력서 중 실제 내용이 직무와 가장 맞는 버전을 골라 지원해줘. 필수 문항은 검증된 자료로 채우고, 허용된 범위는 최종 제출해줘. 이미 지원했거나 제출 결과가 불명확한 공고는 다시 누르지 마.

저장 이력서가 없는 업로드형 폼은 정책에서 승인한 파일만 첨부합니다. 모르는 필수 답변·승인되지 않은 계정·외부 도메인·플랫폼 본인 확인은 해당 공고를 보류합니다. Aside의 필수 승인·로그인·CAPTCHA를 우회하지 않습니다.

## 검증 범위

Python 3.10+ 표준 SQLite 스크립트로 권한·기한·범위·계정·중복·제출 횟수와 확인 불가 상태를 검사합니다. 스크립트는 브라우저를 조작하거나 직무 적합도를 자동 판정하는 API가 아닙니다. 실제 UI·저장 이력서·페이지 변경·접수 증거는 Aside가 확인해야 합니다.

오프라인 테스트는 실제 지원서를 제출하지 않습니다. 사이트에서 완료 증거를 확인하기 전에는 제출 완료로 기록하지 않습니다. 불확실한 제출은 다음 실행에서도 차단됩니다.
