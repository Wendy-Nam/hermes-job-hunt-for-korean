# Portfolios — 예시 (가상 인물)

## 0. 포트폴리오 옵션

- **소개**: 영업 조직이 숫자를 믿고 움직일 수 있게 만드는 일을 합니다. CRM 데이터 구조 설계부터 리포팅 자동화, 사내 AI 도구까지 직접 만들어 운영해 왔습니다.
- **프로젝트마다 새 페이지**: 아니오
- **최대 프로젝트 수**: 6

## 📌 주요 포트폴리오 목록

### 1. 영업 리포팅 자동화 파이프라인
- **기간**: 2022.04 ~ 2022.09
- **유형**: 회사 프로젝트
- **팀 구성**: 세일즈옵스 1 · 데이터 엔지니어 1
- **역할**: 기획·파이프라인 개발 리드
- **기여도**: 80%
- **개요**: CRM 데이터를 매일 수집·정제해 경영진 대시보드로 자동 배포하는 파이프라인
- **배경·문제**: 주간 보고를 매번 수작업으로 만들어 영업기획팀이 주 10시간을 쓰고, 수치가 보고서마다 달랐습니다.
- **해결**: Salesforce API로 원천 데이터를 매일 적재하고 지표 정의를 한곳에 모은 뒤, Looker Studio 대시보드와 Slack 요약을 자동 발송했습니다.
- **기술 스택**: Python, Salesforce API, BigQuery, Looker Studio
- **성과**: 보고 리소스 80% 절감, 데이터 정합성 이슈 월 12건 → 1건
- **배운 점**: 지표 정의를 코드보다 먼저 합의해야 자동화가 신뢰를 얻는다는 것을 배웠습니다.
- **GitHub**: https://github.com/haneul-kim/sales-report
- **문서**: https://haneul-kim.github.io/sales-report
- **이미지**: images/reporting-dashboard.svg | 자동 배포되는 주간 파이프라인 대시보드

### 2. LLM 기반 영업 메일 초안 도구
- **기간**: 2024.01 ~ 2024.03
- **유형**: 사내 사이드 프로젝트
- **팀 구성**: 단독
- **역할**: 기획·개발·운영
- **기여도**: 100%
- **개요**: 고객 이력과 제품 정보를 바탕으로 후속 메일 초안을 만들어 주는 Slack 도구
- **배경·문제**: 영업사원이 미팅 후 후속 메일 작성에 1인당 주 3시간 이상을 쓰고 있었습니다.
- **해결**: CRM 활동 기록과 제품 문서를 검색해 LLM 프롬프트에 넣고, Slack 명령 한 번으로 초안을 받도록 했습니다.
- **기술 스택**: Python, LLM API, Slack Bolt
- **성과**: 영업사원 1인당 주 3시간 절감, 팀 12명 전원 사용
- **데모**: https://example.com/demo/mail-draft

### 3. 리드 스코어링 모델
- **기간**: 2023.02 ~ 2023.05
- **유형**: 회사 프로젝트
- **팀 구성**: 세일즈옵스 1 · 마케팅 1
- **역할**: 모델 설계·영업팀 온보딩
- **개요**: 인바운드 리드를 전환 가능성 순으로 정렬하는 점수 모델
- **배경·문제**: 영업과 마케팅이 좋은 리드의 기준을 두고 합의하지 못했습니다.
- **해결**: 과거 6개월 리드를 함께 검토해 기준을 합의하고, 행동·기업 속성 가중치 모델을 CRM에 적용했습니다.
- **기술 스택**: SQL, Salesforce, Python
- **성과**: 영업 전환율 18% → 27%
