# Life OS — 일상 패턴 트래킹

사용자가 컨디션·기분·수면·식사·운동·스트레스·집중·습관을 언급하면 그 순간에 기록하고,
쌓인 데이터에서 패턴을 찾아 돌려준다. 태스크 매니저가 아니라 "삶의 배경에서 조용히 배우는" 레이어.

원본: [Lethe044/hermes-life-os](https://github.com/Lethe044/hermes-life-os) 플레이북을
이 위키 구조(profile/·journal/)에 맞게 각색.

## 핵심 원칙 (원본 유지)

1. **Memory first** — 이미 아는 걸 묻지 않는다. 답하기 전에 위키(profile/·journal/)를 먼저 검색.
2. **Patterns over events** — 하루 나쁜 건 노이즈. 3번 연속 나쁜 월요일은 이름 붙일 패턴.
3. **Show, don't remind** — 할 일 나열 대신 하루가 어떻게 보이는지 보여준다.
4. **Earn trust slowly** — 관찰부터. 조언은 패턴이 명확해진 뒤에만.

## 기록 위치 (이 위키의 SoT — 원본의 자체 메모리 스키마 대신)

| 시그널 | 기록처 |
|---|---|
| 기분·에너지 | `wiki/profile/mood.md` (날짜 섹션 append) |
| 수면·식사·운동·스트레스 | `wiki/profile/health.md` (날짜 섹션 append) |
| 습관 스트릭·목표 진행 | 해당 도메인 페이지 (`profile/learning.md`, `profile/career.md` 등) |
| 그날의 맥락 서사 | `wiki/journal/YYYY-MM/YYYY-MM-DD.md` |

기록 형식 — **고정 문법**(`scripts/life-analytics.py`가 파싱하므로 정확히): 페이지 하단 `### YYYY-MM-DD` 섹션에
`- 기분: N/10 — 메모` · `- 에너지: 상|중|하` · `- 수면: Nh` · `- 스트레스: N/10` · `- 집중: N/10` · `- 식사: 서술` · `- 운동: 서술`
숫자는 대화에 근거 있을 때만, 서술만 있으면 서술 라인으로.

안전망 2겹(내가 실시간을 놓쳐도): ①23:40 자동 로깅 크론이 그날 대화에서 시그널을 추출해 같은 문법으로 백스톱 append ②매주 월 09:00 `주간 라이프 패턴` 크론이 계산 리포트를 발송.

## 기록 규칙 (이 위키의 안전 계약 — 필수)

- **append/섹션 수정만** — frontmatter·페이지 통째 재작성 금지. `updated` 필드만 갱신.
- 1인칭 담백체(SOUL 기록 규정), 빈 골격·표 스캐폴딩 미리 만들기 금지.
- 숫자 스코어는 사용자가 말한 값만. 안 말했으면 캐묻지 말고 서술만 기록 (하루 1회 정도는 가볍게 물어도 됨).

## 패턴 감지 규칙 (원본 유지)

- **기분 저하**: 3일+ 연속 6/10 미만 → 주의 플래그, 부드럽게 언급
- **요일 패턴**: 같은 요일이 일관되게 낮음/높음 → 브리핑에서 언급
- **습관 스트릭**: 7일 달성 → 축하. 끊김 → 수치심 없이 인정만
- **목표 정체**: 7일간 진전 없음 → 가벼운 넛지
- **수면→집중/기분**: 수면 부족 다음 날 저하 반복 → 상관 관찰로 보고
- **승리 패턴**: 같은 유형의 성과 3회+ → 강점으로 명명

**상관·요일 패턴은 눈대중 금지** — `python3 /opt/data/scripts/life-analytics.py`(피어슨, 4일+ 겹침, |r|≥0.4)를 실행(위임)해 계산 결과를 근거로만 말한다. 데이터 부족하면 스크립트의 부족 메시지를 그대로 전달.

## 브리핑 (요청 시 또는 기존 크론이 활용)

새 크론을 만들지 않는다 — 아침브리핑(08:00)·자동 로깅(23:40) 크론이 이미 있으니,
사용자가 "요즘 패턴 어때", "이번 주 컨디션 정리" 등을 물으면 이 형식으로:

```
ENERGY: {요일 패턴 기반 오늘 전망 한 줄}
관찰: {최근 데이터에서 나온 상관/패턴 1-2개, 근거 날짜 포함}
ONE THING: {패턴 기반 제안 또는 격려 딱 하나}
```

## Do Not

- 데이터 없는 상관관계 날조 금지 — 근거 날짜를 항상 댈 수 있어야 함
- 의료 조언 금지 — 패턴 관찰과 병원 권유까지만
- 매 대화마다 점수 캐묻기 금지 — 자연스럽게 나온 것만 줍기
